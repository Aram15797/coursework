Խնդիրը և նպատակը

Ինչո՞ւ ևս մեկ task-management համակարգ

Ավանդական նախագծերի կառավարման համակարգերում տվյալների բազան «թաքնված» է ծրագրավորման մակարդակից։ Ուսանողը տեսնում է միայն վերջնական արդյունքը, բայց ոչ թե ինչպես են ձևավորվում SQL հարցումները։

05 / 07
★ Հիմնական առանձնահատկություն

Տվյալների բազայի վիզուալիզացիայի շերտ

🔍

1. Inline Query Log

QueryInterceptorMiddleware-ը գրավում է SQLAlchemy-ի յուրաքանչյուր հարցումը՝ ContextVar-ի և engine event-երի միջոցով։

Գրավվում է՝ SQL տեքստ, գործողություն (SELECT/INSERT...), աղյուսակներ, տևողություն (ms), տողերի քանակ, պարամետրեր։ Ուղարկվում է X-DB-Query-Log վերնագրով։

🗺️

2. Schema Explorer

Միայն ադմինի համար (/db-explorer)՝ կենդանի սխեման ինտերակտիվ React Flow ER դիագրամի տեսքով։

Տվյալները՝ information_schema և pg_catalog-ից. աղյուսակների վիճակագրություն, ինդեքսներ, EXPLAIN պլան։

# Frontend-ում axios interceptor-ը վերծանում է header-ը const log = decodeBase64(response.headers['x-db-query-log']); inspectorStore.push(log); // → Prism-ով գունավորված SQL + Recharts գծապատկեր + N+1 զգուշացում

DB Inspector վահանակը միանում է header-ի «DB Inspector» կոճակով և ցույց է տալիս վերջին 100 հարցումները։
